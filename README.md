# Vaquero Valley 🤠

Juego de rancho gratis para toda la familia: siembra, cuida animales, procesa productos en fábricas y haz crecer tu rancho.

## Cómo se publica
Este repositorio usa **GitHub Pages**: cada vez que se guarda un cambio en `index.html` en la rama `main`, el juego se actualiza solo en la dirección pública.

## Dónde cambiar cosas sin programar
- **Eventos especiales**: busca `const EVENTS=` dentro de `index.html`. Cada evento tiene nombre, fechas (`AAAA-MM-DD`) y descripción.
- **Artículos de personalización**: busca `const COS_ITEMS=`. Los artículos de un evento llevan `ev:'id-del-evento'`.

## Reglas del juego
Sin contenido para adultos, sin violencia y sin magia. Apto para niños y adultos.
